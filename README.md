# MikroTik Restream Route Sync

🚀 اسکریپتی برای همگام‌سازی مسیرهای IP سرویس Restream روی روترهای MikroTik.

## توضیح کوتاه
این اسکریپت با استفاده از Python، IP های سرورهای Restream را دریافت کرده و مسیرهای مناسب را روی روتر MikroTik شما اضافه یا بروزرسانی می‌کند.  
این کار به شما کمک می‌کند تا جریان‌های Restream بدون مشکل از طریق روتر شما عبور کنند.
برای راحت تر split کردن ترافیک بین اینترنت عادی و نتی که با آن میخواهید استریم کنید.

## ویژگی‌ها
- دریافت خودکار IP های سرورهای Restream
- تبدیل IP ها به CIDR /24
- بررسی و بروزرسانی مسیرهای موجود روی MikroTik
- افزودن مسیرهای جدید با کامنت شامل ورژن Restream
- ذخیره امن اطلاعات اتصال در فایل ENV (~/.restream_env)

## پیش‌نیازها
- Python 3
- pip3
- سیستم عامل Linux (تست شده روی Ubuntu/Debian)
- دسترسی به MikroTik با مجوز ایجاد/ویرایش مسیرها
