# 📡 MikroTik Stream Route Manager & Web Panel

🚀 ابزار مدیریت و همگام‌سازی هوشمند مسیرهای ترافیک استریم (**Restream.io** و **Aparat RTMP**) روی روترهای **MikroTik RouterOS** با پنل تحت وب مدرن و چکر زنده اینترفیس‌ها.

این پروژه برای **تقسیم هوشمند ترافیک (Split Tunneling / Policy Routing)** طراحی شده است؛ به این صورت که ترافیک استریم شما از یک اینترنت/اینترفیس اختصاصی (مثلاً مودم با آپلود بالا یا سیم‌کارت مجزا) عبور می‌کند، بدون اینکه ترافیک بقیه سیستم‌ها و وب‌گردی دچار تداخل شود.

---

## 🌟 ویژگی‌های کلیدی

* **🖥️ پنل تحت وب شیک و مدرن (Dark Mode):** دسترسی سریع از طریق مرورگر کامپیوتر یا موبایل بدون نیاز به SSH.
* **🟢 چکر زنده اینترفیس‌ها (Live Interface Checker):** دریافت آنی و زنده لیست اینترفیس‌های فعال میکروتیک (Ethernet, PPPoE, WireGuard, LTE, VLAN) به همراه وضعیت و آی‌پی.
* **🇮🇷 پشتیبانی کامل از سرورهای آپارات (Aparat RTMP):** تبدیل خودکار دامنه `rtmp.cdn.asset.aparat.com` به ساب‌نت شبکه `/24` صباایده.
* **🚀 پشتیبانی از سرورهای Restream.io:** دریافت خودکار لیست آی‌پی سرورهای Restream از طریق API رسمی و تبدیل به CIDR.
* **➕ قابلیت افزودن دامنه‌ها و آی‌پی‌های دلخواه:** اضافه کردن پلتفرم‌های دیگر مثل Twitch، YouTube RTMP یا هر دامنه دلخواه؛ سیستم خودکار با DNS آی‌پی را استخراج و روت می‌زند.
* **⚡ تغییر آنی خروجی اینترنت (One-Click Gateway Switch):** انتخاب اینترفیس خروجی از منوی کشویی و اعمال بلافاصله با یک کلیک.
* **🔒 پورت اختصاصی امن و غیررایج (پیش‌فرض: `18542`):** قابل تنظیم به هر پورت دلخواه با امکان فعال‌سازی رمز عبور (Basic Auth).
* **⚙️ پشتیبانی از حالت خط فرمان (CLI):** امکان اجرای مستقیم از طریق ترمینال بدون وب‌پنل.
* **🔄 سرویس دائمی سیستم (systemd):** بالا آمدن خودکار پس از ری‌استارت سرور.

---

## 📦 پیش‌نیازها

* سیستم‌عامل لینوکس (تست شده روی Ubuntu / Debian / CentOS بر روی سرور T620)
* پایتون نسخه 3.8 به بالا و `pip3`
* روتر میکروتیک با سرویس API فعال (`/ip service enable api` - پورت پیش‌فرض 8728)

## 🚀 نصب و راه‌اندازی سریع روی سرور

### ۱. دریافت پروژه و اجرای اسکریپت نصب:
```bash
git clone https://github.com/Adler-tak/mikrotik-restream.git
cd mikrotik-restream
chmod +x setup.sh rstreamip.py app.py
./setup.sh
```

اسکریپت `setup.sh` تمام نیازمندی‌های پایتون را نصب کرده و به صورت خودکار سرویس پس‌زمینه `mikrotik-stream.service` را می‌سازد و اجرا می‌کند.

---

## 🌐 دسترسی به پنل تحت وب

پس از اجرای سرویس، پنل وب با آی‌پی سرور شما در دسترس است:
👉 **`http://192.168.2.209:18542`** (یا پورت انتخابی شما)

### کار با پنل:
1. اینترفیس یا گیت‌وی خروجی مورد نظر برای استریم را از منوی کشویی انتخاب کنید.
2. پلتفرم‌های مورد نظرتان (Restream, Aparat, Custom) را فعال نگه دارید.
3. دکمه **«⚡ همگام‌سازی و تغییر مسیرها (Sync)»** را بزنید.
4. تمام مسیرها در کسری از ثانیه روی میکروتیک ایجاد و اعمال می‌شوند!

## 💻 اجرای دستی یا حالت خط فرمان (CLI)

اگر ترجیح می‌دهید بدون وب‌پنل و از طریق ترمینال عملیات را انجام دهید:

```bash
# اجرای حالت خط فرمان (CLI)
python3 rstreamip.py --cli
```

یا برای اجرای دستی سرور وب:
```bash
python3 app.py
# یا
python3 rstreamip.py --port 18542
```

## ⚙️ تنظیمات فایل محیطی (`.env`)

فایل `.env` به صورت خودکار ساخته می‌شود اما می‌توانید آن را به دلخواه ویرایش کنید:

```ini
MIKROTIK_IP=192.168.2.1
MIKROTIK_USER=admin
MIKROTIK_PASSWORD=your_password
MIKROTIK_PORT=8728
PORT=18542
WEB_USERNAME=
WEB_PASSWORD=
DEFAULT_GATEWAY=
```

## 🛠️ دستورات مدیریت سرویس در سرور

```bash
# مشاهده وضعیت اجرای وب‌پنل
sudo systemctl status mikrotik-stream

# ری‌استارت سرویس
sudo systemctl restart mikrotik-stream

# مشاهده لاگ‌های زنده
sudo journalctl -u mikrotik-stream -f -n 50
```
